1 — Session starts automatically

Trigger: SessionStart hook

The session-start.sh hook fires immediately, injecting all three CONTEXT files into the conversation. Claude reads accumulated memory before your first message.

Automatic — no action needed

2 — Work as normal

During the session

Code, debug, plan, ask questions. Claude retains awareness of all prior errors, decisions, and project context. The loop is quietly running in the background.

Just chat normally

3 — End-of-session: run the skill

Trigger: manual or Stop hook reminder

Before closing the chat, invoke the compound-loop skill. Claude will update all three files with everything that happened — errors, decisions, summary, and project status.

/compound-loop

4 — Files are committed

After the skill runs

The three updated CONTEXT files are committed to the branch. The next session will load this richer context — making every subsequent session more informed than the last.

git add CONTEXT/ && git commit

5 — Repeat, compounding

Every session after

Each loop iteration adds a layer of context. Over time, Claude develops a deeply accurate model of the project, its history, its mistakes, and its goals — without relying on conversational memory.
